C# Calculator
A simple calculator application built with C# that performs basic arithmetic operations.

Features :
- Addition
- Subtraction
- Multiplication
- Division
- Simple and easy-to-use interface

Technologies Used :
- C#
- .NET / Visual Studio

Purpose :
This project was created as a practice project to strengthen my understanding of C# fundamentals, user input, operators, and basic programming logic.

How to Run :
1. Clone or download this repository.
2. Open the project in Visual Studio.
3. Build and run the project.
4. Enter the required values and select an arithmetic operation.
